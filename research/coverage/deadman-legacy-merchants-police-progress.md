# Four more English starting instructions

Checked on 2026-09-24 against the cited rulebook pages. The research drafts and approved catalog entries contain the source location and file hash for each game and edition.

| Game | BGG ID | Source pages | Opening instruction | Random mix |
| --- | ---: | --- | --- | --- |
| Dead Man's Cabal | 264321 | PDF 4–6 | Last player to have raised the dead takes the first Active Player role. If no one has done that recently, choose by another method. | No |
| Legacy: Gears of Time | 119781 | PDF 4, 6 | Randomly choose who picks a player-order position first; the watch-time idea is only a suggestion. | No |
| Merchants of Muziris | 231215 | PDF 4, 8–9 | Last player to eat a mango starts the first round. | Yes |
| Police Precinct | 118536 | PDF 2, 4 | Most recent law-enforcement contact picks a character first; the last character picker receives the First Player Shield. | No |

The Dead Man's Cabal rulebook credits Pandasaurus Games ©2019. The Legacy rulebook credits Floodgate Games ©2013; the [publisher's product page](https://floodgate.games/products/legacy-gears-of-time) corroborates the game identity. The 2019 Merchants booklet matches the Kolossal Games second-edition artwork [posted by the publisher](https://boardgamegeek.com/image/4547366/merchants-of-muziris). The Police Precinct rulebook credits Common Man Games, whose [edition record](https://commonman.com/policeprecinct/) distinguishes the original first-edition rulebook from its later revision.

Only Merchants supplies a portable criterion that directly selects the opening player. The others preserve the game-specific roles and fallbacks in their catalog entries.
