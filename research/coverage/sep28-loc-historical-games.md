# Library of Congress historical-game follow-up — 2026-09-28

This bounded source pass reviews three Library of Congress digitized objects
against the 5,248-identity live directory at `9aa3890f6b689cf062b4e339c38963987b551100`.
Two distinct physical games are accepted as **identity-only** records in
[`publisher-identities.json`](publisher-identities.json), taking local coverage
to **5,250**. No starting-player rule, BoardGameGeek ID, image, or modern
edition correspondence is approved.

| Object | Decision | Original-artifact evidence |
| --- | --- | --- |
| [*Jeu géographique de la République Française : présenté à la Convention Nationale*](https://www.loc.gov/item/79695291/) | Accept one Basset c.1795 printed board | The [hand-colored game sheet](https://tile.loc.gov/image-services/iiif/service:gmd:gmd5:g5831:g5831f:ct001461/full/pct:25/0/default.jpg) prints the title, Mauborgne credit, numbered map route, rules, and Chez Basset Paris imprint. The Library catalogs one 55 × 80 cm game sheet, LCCN 79695291. The bracketed 1795 date is approximate, so no more precise printing is claimed. |
| [*Going to Klondyke*](https://www.loc.gov/item/99446193/) | Accept one Klondyke Game Co. 1897 printed map game | The [original map](https://tile.loc.gov/image-services/iiif/service:gmd:gmd437:g4371:g4371a:mf000035/full/pct:25/0/default.jpg) explicitly calls itself an amusing and instructive game, prints numbered pin-placement/scoring rules, credits May Bloom, and names the Klondyke Game Co. of San Francisco. The Library catalogs the physical 38 × 48 cm sheet, LCCN 99446193. It is a map-based tabletop game; no broader Klondike title is joined. |
| [*Geographical Conversation Cards*](https://www.loc.gov/item/2002620534/) | Hold | The 1824 boxed set has 30 state map cards, paired question-and-answer cards and a Goodrich booklet. The scanned material establishes an educational card product, but the inspected page does not establish a playable contest or turn structure. It remains a source lead rather than a game identity. |

The two accepted images were inspected as original publisher-authored artifacts.
The Library's [Basset item rights statement](https://www.loc.gov/item/79695291/)
and [Klondyke item rights statement](https://www.loc.gov/item/99446193/)
say the World Digital Library material is free to use and reuse absent
restrictions. Only bare title, imprint, year, physical format and evidence
summary enter this site's registry; no artwork or rule text was copied into
the site. The ignored image files were used for review and SHA-256 checks.
The [validation script](../../scripts/prepare-loc-historical-game-batch.mjs)
re-fetches both exact image URLs and checks their byte counts and hashes, plus
both accepted record revisions. Both accepted names and the one search alias
were absent from the active 5,248-name projection; content validation and the
5,250-count coverage check passed.

The earlier Smithsonian *In the Chips* and *Pot Luck* holds remain unchanged.
Additional Oink product leads observed during this pass were excluded because
the current [Oink site terms](https://oinkgames.com/en/page/terms-of-use/)
bar automated access and systematic retrieval to compile a directory without
written permission. No Oink data was added from this follow-up.
